ngxsmk-socket-io

Modern Angular sockets, documented by example.

Typed Socket.IO for standalone Angular apps — RxJS streams, Signals, SSR-safe defaults, and a small public API.

Open playground Advanced API Read the guide

Install

Add the library and the official Socket.IO client peer dependency.

Standalone setup

Register once with provideSocketIo — no NgModule required.

What this demo covers

  • Guide — first patterns for typing, lifecycle, and multi-socket
  • Playground — live connect, chat, emitWithAck, auth
  • Advanced — every feature explained with snippets
  • Angular 16+ / Ionic 7–9 compatibility (see docs)
  • SSR-safe defaults, Signals, and testing helpers
Need a server?

Locally: run npm run example:server, then Connect from the playground.

On GitHub Pages: host examples/chat-server on HTTPS (Render/Railway/Fly), paste that URL in the playground, or bake it with SOCKET_URL when building.
